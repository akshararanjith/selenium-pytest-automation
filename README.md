# Selenium & Pytest Automation Framework

A scalable web automation testing framework built using Python, Selenium WebDriver, and Pytest. This project demonstrates industry-standard testing practices, clean execution logs, and robust assertions.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Testing Framework:** Pytest
* **Automation Tool:** Selenium WebDriver
* **Design Pattern:** Page Object Model (POM) blueprint baseline

## 🚀 Key Framework Features
* **Robust Assertions:** Clean test validation checks to ensure UI elements load correctly.
* **Smart Waits:** Implementation of Implicit/Explicit waits to prevent flaky tests and handle dynamic element loading.
* **Test Isolation:** Independent test execution setups to ensure clean state baselines.
